# Timeline

The repository opens on 2026-05-22 with commit 0da6718 "first commit" already carrying essentially the whole feature set: the Gemini Live WebSocket session, Live2D auto-discovery, lip sync, screen awareness, personalities, and both animate_avatar tool generation and ProceduralAnimator.loadCustomActions (which has never gained a caller). The same day brings "gemini live fix", logging plumbing, be664c7 optimizing CPU/GPU usage and preventing screenshot input blocking, then 05-23 fixes for sync issues, i/o issues, and memory usage.

From PR #1 onward the history becomes a long Jules-assisted code-health and performance campaign, visible as jules-* branches merged through PR #10 through #20: e3426a2 moved config loading off the event loop onto fs.promises; a0c179e prefixed unused AudioWorkletProcessor parameters; several commits removed unused variables and catch bindings (#12, #13, #16 via db66c19, #19 via 2b8f3b3); 1180953 optimized the ProceduralAnimator parameter loop (#15); 887b4e6 and 27fc851 reduced ToolDefinitions complexity (#17, #18); and 4d12ec4 centralized WebSocket message sending behind GeminiLiveSession._sendMessage (#20). The .jules/bolt.md notebook records the measured wins from this era - sync filesystem calls blocking the event loop for ~193-318ms reduced to ~83ms, and the animator frame loop benchmarked ~53% faster by precomputing segment parameter arrays instead of allocating Sets per tick. Note that bolt.md's own headers mix 2024-05-22 and 2026-05-22 dates in a repo born in 2026; the agent-authored dating is evidently sloppy there.

Two structural changes close the story. Commit aab5aa9 "Optimization local changes" on the local-optimization branch (merged as 2edef3e) is where git log -S pins the removal of animate_avatar generation from generateTools - the tool now survives only as dead code, which [[Discrepancies]] itemizes against the README's still-standing AI-composed-animation claims. After that merge come only 491daf7 "minor tools error" and d2d1f6a "logs" (HEAD), leaving 55 commits total across main and the surviving local-optimization branch. Back to [[Home]].
