# Electron Main Process

main.js registers a privileged local:// scheme before app ready (standard, secure, bypassCSP, fetchAPI, CORS enabled) and serves it through registerFileProtocol, letting the sandboxed renderer load arbitrary disk paths like model3.json assets via local:/// URLs. createWindow applies the overlay recipe: transparent, frameless, alwaysOnTop 'floating', backgroundColor #00000000, backgroundThrottling left enabled. A 16ms setInterval polls screen.getCursorScreenPoint and forwards coordinates relative to the window as global-mouse-move, which is what lets the avatar's eyes follow the cursor across the entire desktop rather than just inside the window ([[Avatar Rendering]]); --dev detaches DevTools and console-message events are mirrored to stdout.

The IPC surface, all registered in setupIPC: set-ignore-mouse-events and move-window plus resize-window (edge-directional resizing with a 200px floor) for window manipulation; get-screen-source-id and capture-screen for display capture; get-api-key/set-api-key where set encrypts via safeStorage (DPAPI on Windows) into encryptedApiKey and falls back to plaintext apiKey only when encryption is unavailable, while get-config deliberately strips both fields before returning; find-default-model, an async recursive search preferring models/default before scanning all of models/ for *.model3.json; select-model-file opening a dialog filtered to .model3.json; open-external-link restricted to http/https protocols; save-config merging partials and restarting the ScreenCaptureService when interval or enablement changed; quit-app; toggle-settings relayed to the renderer; and the logging pair save-chat-log appended to userData/logs/chat.log through a lazily-created write stream (deliberately ipcMain.on fire-and-forget to avoid IPC queue backpressure) and save-screenshot-log writing JPEGs under logs/screenshots/.

screenCapture.js schedules thumbnails on a base interval of seven minutes varied by plus-or-minus thirty percent each cycle so captures feel non-mechanical, grabs the primary display via desktopCapturer at 854x480 JPEG quality 40, writes bytes to disk directly ("to prevent IPC echo chamber"), and merely signals trigger-periodic-capture to the renderer, which does its own higher-quality grab - see [[Screen Awareness]]. tray.js builds Show/Hide, Settings, Lock Model (click-through), and Quit around a placeholder purple icon if assets/icons/tray.png is missing; notably the lock-model listener lives here rather than in setupIPC, keeping one mutable isLocked owner that toggles setIgnoreMouseEvents(true, forward:true) and broadcasts lock-state-changed.
