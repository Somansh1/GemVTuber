# Overlay UI

InteractionOverlay owns everything floating over the avatar: the status indicator cycling idle/connected/listening/speaking/error labels, the mic indicator whose click toggles mute, timed subtitles, a chat message list appended from GeminiLiveSession text events, and a right-click context menu (settings, lock, screenshot, open logs, toggle mute, change model, quit). The chrome hides itself until mouse activity and re-hides after 2.5 seconds of stillness via a ui-hidden body class, using mousemove/mouseenter/contextmenu because mousedown is swallowed by the CSS drag region. Window dragging rides -webkit-app-region: drag rather than JS, while eight edge/corner resize handles stream incremental deltas through the resize-window IPC with a 200px floor enforced main-side. A focus border class appears whenever the window has keyboard focus.

Click-through deserves its own note because the code documents reversing course: manual hit-testing against pixel transparency was removed because it conflicted with PixiJS event handling and made buttons unclickable, so setIgnoreMouseEvents(false) is forced on startup - reliable dragging and clicking won over transparent-area pass-through. True click-through survives only as the explicit Lock action: the lock button calls electronAPI.lockModel(true) with a subtitle telling users to unlock from the tray, and tray.js remains the single owner of lock state, toggling setIgnoreMouseEvents(true, forward:true) and echoing lock-state-changed back so the renderer can announce "Model unlocked" ([[Electron Main Process]]).

SettingsPanel maps the settings DOM onto a config object: API key input (password-masked with a visibility toggle, persisted on change via setApiKey), model file picker showing the chosen filename, avatar scale slider, personality select with a conditionally-shown custom prompt textarea, screen capture toggle plus interval slider, microphone device dropdown populated from MicCapture.getDevices, volume slider, and an external link to Google AI Studio for key creation. Every field change emits through onSave, which index.js turns into live applies plus config persistence plus the personality-change reconnect dance ([[Personality and Memory]]); the tray's Settings item reaches this same panel through the toggle-settings relay.
